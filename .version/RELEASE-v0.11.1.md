# Release v0.11.1

> 核心变化：最终总结的「自我 review 结论」从插入式括号说明改为独立成项，措辞统一为规范句式，前后对比的说明层级也随之理顺。

## 🚀 Features
- 最终总结要求拆分为两项：先给自我 review 结论（一句话说明是否符合要求或存在什么漏洞），再给前后对比。
- 前后对比的补充说明独立成段，避免原括号注释与实际条目混排导致的阅读歧义。
